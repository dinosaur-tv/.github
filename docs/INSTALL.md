Начните с бота: он создаёт дом и выдаёт код для телевизора. Пульты — по желанию, всё то же самое есть в мини-приложении.

## Android TV

Магазина нет, APK ставится вручную.

1. Настройки → Безопасность и ограничения → разрешите установку из выбранного источника.
2. Установите APK любым способом:
   - **Downloader** (или другой браузер для ТВ): откройте ссылку на релиз и скачайте `.apk`;
   - **USB-флешка**: скопируйте файл, откройте файловым менеджером;
   - **adb** с компьютера: `adb connect <IP телевизора>:5555`, затем `adb install dino-tv-vX.Y.Z.apk`.
3. Откройте приложение, разрешите доступ к уведомлениям (музыка) и показ поверх приложений (напоминания).
4. На экране появится шестизначный код. Введите его в мини-приложении: «Ещё → Код ТВ или телефона» → «Связать».

Адрес сервера зашит в APK на этапе сборки. Ставьте только сборку своего сервера.

## Android-телефон

1. Скачайте APK из релиза, откройте файл, разрешите установку из этого источника.
2. Нажмите «Сервер» и укажите свой `https://home.example.com`.
3. Войдите: в мини-приложении «Ещё → Код для моего телефона», введите этот код здесь.

## iPhone: sideload

В релизе лежит **неподписанный** IPA. Apple не даёт установить его напрямую: файл нужно подписать своей учётной записью. Приложения из App Store для Dino нет.

Что понадобится: Apple ID и компьютер.

- **Sideloadly** (Windows/macOS): подключите iPhone кабелем, перетащите IPA, введите Apple ID → Start.
- **AltStore** (Windows/macOS): установите AltServer, затем в AltStore → «+» → выберите IPA.
- **Xcode** (macOS): соберите проект из `ios-app` со своей Team — самый надёжный путь.

После установки: Настройки → Основные → VPN и управление устройством → доверьтесь своему профилю разработчика.

Бесплатный Apple ID подписывает приложение на **7 дней** — потом его нужно переподписать тем же способом. Платный аккаунт разработчика даёт год. Это ограничение Apple, не Dino.

Дальше: кнопка «Сервер» → ваш адрес → вход по одноразовому коду, как на Android.

## Проверка

Ставьте только те файлы, которые собрал ваш CI из вашего репозитория. Рядом с APK в релизе лежит `SHA256SUMS.txt` — сверьте:

```bash
sha256sum -c SHA256SUMS.txt
```

Подпись APK меняться не должна: приложение, подписанное другим ключом, не установится поверх — придётся удалять старое вместе с его данными.

## Свои релизы

Workflow `Release APK` собирает и подписывает APK по тегу. Заранее задайте в репозитории:

- переменные `DINO_HOME_URL` и `DINO_API_BASE_URL` (только `tv-app`);
- секреты `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`.

Keystore создаётся один раз и хранится вне Git:

```bash
keytool -genkeypair -v -keystore release.jks -alias dino -keyalg RSA -keysize 4096 -validity 10000
base64 -w0 release.jks   # значение секрета ANDROID_KEYSTORE_BASE64
```

Потеряете keystore — обновить установленное приложение будет нечем.
